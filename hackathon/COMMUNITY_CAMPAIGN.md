# MANDAVEX community campaign — draft, not published

**Status: IMPLEMENTED BUT UNVERIFIED.** These are organic outreach drafts. No post or invitation has been sent. Do not promise a live deployment or competition eligibility before those gates pass.

## Core message

MANDAVEX explores a practical infrastructure gap for autonomous agents: how to authorize one bounded action, for one executor, with a fixed payload and expiry, then leave an independently checkable receipt. The prototype uses Agent ID checks at execution and a task handoff that binds reviewer acceptance to the submitted artifact hash. Today the Guard is a pre-deployment candidate; the public site’s Arena is a local simulation. We are looking for technical feedback and, only after reviewed deployment, voluntary participation from genuine Agent ID holders.
