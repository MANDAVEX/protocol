# Evidence directory

Store reproducible build logs, test output, deployment receipts, verified source references, and adoption queries here. Each artifact must state its source, timestamp, network, command/query and limitations. Do not store private keys, user secrets, or fabricated screenshots/results.

`runtime-test-report.txt` records local EVM tests and a BSC mainnet-state fork run. `bsc-fork-deployment-estimate.json` records the fork deployment receipt gas units and constructor argument, not a live fee. `slither-report.txt` records static-analysis output and its scope. `agent-id-bsc-rpc-check.json` records registry RPC observations.

No production deployment or qualifying-user evidence exists yet.
